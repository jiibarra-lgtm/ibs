Esto es un relevamiento a partir de resultados de búsqueda públicos. Para completarlo hacen falta esas herramientas o Search Console, una vez que tengas datos propios.

## Búsquedas que ninguno parece cubrir bien (hipótesis a validar con Keyword Planner)
- "dispenser en comodato" + CABA.
- Guías comparativas (Z vs V, común vs concentrada, gel vs 70%).
- "insumos de limpieza para consorcios" y "factura a nombre del consorcio".
- Contenido para proveedores del Estado (BAC, Convenios Marco).

## Estrategia para superarlos
1. **Páginas pilar por intención** (ya creadas) + fichas de producto y kits existentes.
2. **Guías con respuesta directa:** formato apto para AEO y GEO.
3. **Autoridad:** perfiles, directorios y proveedores (ver `06`).
4. **Señal de confianza:** "fabricantes y distribuidores desde 1985" + reseñas reales.
5. **Ads** en las búsquedas de alta intención mientras se gana posicionamiento orgánico.
